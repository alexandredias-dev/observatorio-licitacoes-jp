# observatorio-licitacoes-jp

Pipeline que coleta diariamente as compras públicas de João Pessoa na API oficial do PNCP, organiza os dados e publica um painel aberto a cidadãos, jornalistas e pesquisadores.

## Escopo

Todas as compras de órgãos sediados em João Pessoa (municipais, estaduais, federais e outros), para ter mais volume e uma visão completa da cidade.

## Perguntas que o painel responde

- Quanto o município publicou em compras por mês?
- Quais órgãos mais compram?
- Qual a proporção de dispensas vs. pregões ao longo do tempo?
- Quais os maiores fornecedores contratados?
